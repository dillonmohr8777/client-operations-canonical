# Kimi publishing contract

This repository is public so the site can always be previewed.

For future edits:

1. Push the complete approved site to `main`.
2. Keep the Vite project structure and `package.json` intact.
3. Run `npm run build` before pushing.
4. Do not commit passwords, API keys, tokens, cookies, `.env` files, unreleased audio, or private client exports.
5. Return the live preview link after pushing: `https://immohrtal-website.netlify.app`

Use GitHub integration with write access to this repository only. Do not request or paste a personal access token into chat.

Automatic preview deployment is connected to pushes on `main`.

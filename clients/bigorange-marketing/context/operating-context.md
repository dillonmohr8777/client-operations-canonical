# BigOrange Marketing operating context

## Relationship

Dillon interviewed with BigOrange on 2026-07-16 and confirmed the new working relationship afterward. The first deliverable is a public, non-password-protected capability showcase that demonstrates how design, terminal workflows, analytics, WordPress, Semrush, SEO, AEO, and GEO can work together.

## What resonated

- Warm, inviting consumer design, especially the recent Philadelphia floral and botanical concepts
- The ability to combine front-end craft with terminal-based analysis and automation
- A portfolio that includes warm B2C, public sector, commercial services, and home services
- Practical methods for making WordPress production faster without removing human review

## Initial opportunity

BigOrange already has a mature WordPress publishing footprint and a strong marketing stack. Public inspection confirms Elementor, Yoast, WP Rocket, Cloudflare, Wordfence, Equalize Digital, a WordPress MCP adapter route, and Yoast Semrush integration routes. The initial opportunity is to connect these tools safely, formalize measurement, improve technical quality, and create a repeatable design and content system.

## Boundaries

- Public evidence is not proof of authenticated access.
- Do not infer private traffic, leads, rankings, conversions, revenue, Core Web Vitals, or Semrush project results.
- Use Semrush OAuth and a dedicated WordPress Application Password only after authorization.
- Start read only and stage changes as drafts.
- Do not publish, send, or change external accounts without explicit approval.

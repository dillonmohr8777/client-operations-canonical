# Authority Hub Staging QA

## Content and source

- [ ] Janice has reviewed all firsthand examples, expert claims, and attribution.
- [ ] Every testimonial and case claim matches the approved source and current public wording.
- [ ] No placeholder, bracketed instruction, draft status note, or invented result remains in visible copy.
- [ ] Metadata, visible headings, FAQ, and schema describe the same content.

## Search and architecture

- [ ] The exact current URL remains canonical and returns HTTP 200.
- [ ] No new competing pillar URL is indexable.
- [ ] One H1; sequential heading hierarchy.
- [ ] Supporting articles link back to the hub and hub links resolve before publication.
- [ ] XML sitemap includes the published URLs and excludes private staging.
- [ ] Breadcrumb and FAQ schema validate and match visible content.

## Accessibility

- [ ] Keyboard order follows the visual order and all controls are operable.
- [ ] Focus is visible on links, buttons, menu items, and FAQ controls.
- [ ] Text and interactive states meet WCAG 2.2 AA contrast.
- [ ] Informative images have meaningful alternatives; decorative images use empty alternatives.
- [ ] Iframes have descriptive titles.
- [ ] Page works at 200% zoom and 320 CSS pixels without horizontal overflow.
- [ ] Reduced-motion preference is respected.

## Performance and runtime

- [ ] Final hero is correctly sized, modern format, dimensioned, and preloaded only if it is the LCP element.
- [ ] Below-fold images and embeds lazy-load.
- [ ] No unexpected console errors or mixed content.
- [ ] Mobile Lighthouse is rerun after caches settle; raw JSON is retained.
- [ ] Desktop Lighthouse is rerun after caches settle; raw JSON is retained.
- [ ] Real-device or throttled mobile review confirms first content is usable without a prolonged blank state.

## Analytics and conversion

- [ ] Primary and secondary CTA links resolve.
- [ ] Form or booking handoff works and preserves consent behavior.
- [ ] CTA events use the agreed naming convention.
- [ ] Test submissions are labeled and excluded from reporting where supported.
- [ ] Conversion reporting remains pending validation until the full analytics and CRM chain is confirmed.

## Publication

- [ ] Exact staging URL and revision are approved.
- [ ] Rollback copy or page revision is available.
- [ ] Publish authority is confirmed for this revision.
- [ ] Live page is checked immediately after publication.
- [ ] Cache, canonical, robots, sitemap, schema, links, and measurement are revalidated on the live URL.

Deliverables

GitHub repository with full codebase

Client provided with access to their accounts and credentials

Set up Resend account and test email delivery
Configure Anthropic API account and test connection

Build core layout components - sidebar, topbar, page wrapper
Build the login page with brand styling
Establish component library for reuse across all pages

4. Phase 3 - Core Development & Feature Buildout

Features Being Built
Main dashboard with stat cards and progress pipeline
Client list with search, filter, and sort
Client detail panel - step progression, onus toggle, notes
Add/edit/remove client functionality
Alerts page - critical, warning, action needed
Advisors page - add, view stats, remove advisors
AI Assistant - natural language client queries
Payment Watch - C&P exam timer, two-group view, mark as paid
Automated daily notification engine
Days-in-step automation - auto-increments daily
Settings page - configurable thresholds and admin email

Tech Lead Tasks (Obaid)
Build all backend API routes and server logic
Implement Anthropic AI integration with client data context
Build automated notification engine with Resend
Set up Supabase cron job for daily days-in-step increment
Build Payment Watch backend logic
Implement all database queries for each feature
Code review on all frontend integrations

Frontend Lead Tasks (Dillon)
Build all page UI - dashboard, clients, alerts, advisors, AI, settings
Build client detail panel with animations
Build Payment Watch page UI
Ensure full mobile responsiveness across all pages
Polish animations, transitions, and loading states

Approval Criteria
All listed features are working in the live environment
David has tested adding, updating, and progressing real clients
AI assistant is responding correctly to client queries
Payment Watch is correctly grouping clients by exam date

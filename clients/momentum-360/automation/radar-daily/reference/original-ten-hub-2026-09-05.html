Built the SAME WAYten times

The geometry is held to the pixel across all ten: the 1310 container, the 73px content edge, the 100px band, the 254+15 carousel item, the 8000x250 stripe. What changes between them is colour, copy and sixty drawings.

See the ten

Every page is the same skeleton: a fixed 100px header whose script tagline swaps for the mark once the hero clears the top of the viewport, a full-height solid identity hero with the mark centered on one calm field, a statement structure, a work grid of two large drawings and numbered tiles, the deep-green section, three more drawings under it, a typographic band over its stripe, an accordion, and the gradient footer.

  • Container 1310 &middot; Content x 73 &middot; Header 100px

The header swap fires at scrollY 486 on a 1440x900 viewport and runs 0.8s cubic-bezier(.85,0,.15,1), translate(-500px) to 0 with opacity. The mark carries a six-second hop in both places it appears. Every illustration loops between 4 and 14 seconds, and all of it stops under prefers-reduced-motion.

  • Swap 485 off / 486 on &middot; mark hop 6s

60 original animated SVGs, six for each business, drawn from that business's own copy: a furnace cutaway and a service van for the 1950 heating shop, a wok, a cleaver on the board and a takeout carton for the Chinese kitchen, an exploded rotor and nine map pins for the parts wholesaler. Each site's six appear once each - two in the grid and four below the green section - with 12 more for the green section and 3 for this page. Inline vector, no raster, no image request, and every fill reads custom properties, so one drawing takes ten different palettes.

  • 75 drawings &middot; 0 image requests &middot; 0 repeats per page

Structure and motion are fixed; colour is not. Brand and accent are read off each business's own logo. Every surface then has its foreground computed rather than assumed, mid-tone accents are deepened until they can carry text at all, and the build fails if a single pair misses AA.

  • 11 of 11 palettes pass every text pair

Every prospect identity now uses the same quiet hero treatment: one centered mark on the site's solid dark field, with the service illustration moved below the fold. Exact first-party logo files are used wherever they exist (8 of the ten); the remaining pages keep their existing typographic identity. No mark sits on an illustrated background, nested card, or added plate.

  • 8 exact logos &middot; 10 solid identity heroes &middot; 0 illustrated logo backgrounds

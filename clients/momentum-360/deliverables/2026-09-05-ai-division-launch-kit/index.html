We start with it. The pilot fixes one handoff rather than selling a replacement.

Can't I just buy an AI subscription?

Yes. This fee covers mapping, implementation, tests, operator training and bounded support.

Will this create more leads?

This pilot improves handling. Lead-generation results require separate evidence.

What if it sends something wrong?

Replies stay internal drafts until a separately approved sending policy exists.

What if the API fails?

Work pauses or enters the exception queue. Ambiguous writes are reconciled before retry.

Is our data used for training?

We verify the selected provider's current contract and settings before using real data. We do not promise an unverified policy.

Why the setup fee?

It funds mapping, implementation, failure testing and handoff for the finite scope.

Can you do everything this week?

We commit dates after access and capacity checks. The initial implementation is not guaranteed within a week.

Who owns it if you leave?

The proposal must specify accounts, code and IP rights, configuration and handoff before sale.

Can we cancel?

Renewal, cancellation, transition assistance and data return or deletion terms are written into the agreement.

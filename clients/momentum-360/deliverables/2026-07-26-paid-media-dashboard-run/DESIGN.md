# Momentum 360 Weekly Dashboard System

## Scene

These dashboards are read from links sent through Slack and email. The authoritative visual source is the established interactive Momentum 360 client-reporting shell preserved in the previously delivered Netlify deployments. New reporting periods update the report object without replacing that shell.

## Durable visual rules

- Preserve the original near-black Momentum 360 canvas, blue interaction accents, amber report labels, client logo treatment, typography, spacing, and motion.
- Preserve the established interactive header and report-status treatment.
- Preserve the executive summary and primary-goal panel.
- Preserve the four-card weekly KPI section.
- Preserve channel performance, weekly chart, wins, watchouts, changes made, next moves, and forms-versus-calls review sections when the source template provides them.
- Preserve each client's existing logo and report category.
- Update only verified report facts, reporting dates, status, and next actions.
- Keep Google Ads, Meta Ads, and distinct client brands separated in the report data.
- Maintain the incumbent responsive behavior and prevent horizontal overflow.

## Information order

1. Momentum 360 header, client, industry, period, and status.
2. Executive summary and primary goal.
3. Forms-versus-calls and review status where supported.
4. Weekly performance KPI cards.
5. Channel performance and chart.
6. Wins, watchouts, changes made, and next moves.
7. Source, latency, and validation notes.

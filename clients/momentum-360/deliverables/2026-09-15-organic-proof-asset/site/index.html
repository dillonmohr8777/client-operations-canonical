A closer look

How the measurement actually works

Every query, every page

We pull the full query and page pairing from Search Console rather than a top twenty summary. That is where the 53,392 pairs come from.

Matched windows only

Growth is compared August against August. Where a property has too little history for a fair baseline, we report the current state and make no growth claim.

Classified by query shape

Each query is sorted into persona prompt, question, conversational or typed keyword, which is what separates machine reads from human visits.

Mapped to the buyer journey

Rankings are sorted into awareness, comparison and decision so a client can see where the pipeline is thin rather than just how many keywords they hold.

Method

Mapping the buyer journey

A ranking list tells you nothing about where a buyer is. A site that ranks only at the decision stage has no pipeline. A site that ranks only at the awareness stage has no revenue.

Build

Pages designed to be the answer

Ranking follows structure. The pages that carry the results above were built to a consistent pattern, and the pattern is deliberate rather than stylistic.

01

One page, one question, answered completely

The buyer's guide that ranks for 352 queries does so because it answers the whole category question in one place instead of splitting it across six thin posts. Depth on a single URL beats breadth across many.

02

Written so a machine can quote a passage

Clear question headings, direct answers immediately beneath them, and defined terms. An assistant lifting an answer needs a self contained passage it can quote. A page that only makes sense read top to bottom gives it nothing to work with.

03

Technical ground cleared first

A site can carry perfect content and still be invisible. We check the unglamorous layer before writing a word: does the domain resolve without the www, is there a sitemap, do old redirects still point somewhere live, is anything blocking a crawler. These are usually small fixes and usually outstanding for years.

04

Location and intent get their own pages

The events operator holds 160 position one rankings because each city and each recurring event has a page that earns its own ranking. One page cannot rank for twenty cities. Twenty pages can.

05

Tracking installed, then verified

Named events for every commercial action, campaign identifiers carried through third party handoffs, and a trigger level audit of the live container so a form submit cannot be counted twice. Double counted conversions are the most common cause of a reported result that never appears in the bank.

Method. Cases one and two, and the query shape analysis, are measured from client owned Google Search Console properties via the Search Analytics API on 15 September 2026. Comparison periods are matched calendar months where a full baseline exists. Where a property has a short measurement history, a single window is reported and no growth claim is made. Case three is third party search index data, which estimates position rather than measuring it, and is labelled as such.
Client identities. Withheld. Figures are unaltered.
Limits. The AI attribution is an inference from query shape and click behaviour, not a labelled source field, because Search Console does not expose one. It evidences that pages rank for the queries answer engines issue and that those appearances behave like machine reads. It is not a count of named citations inside any specific assistant. That is a separate measurement and it is stated separately whenever it is taken.

# M360 Orbit deep knowledge base

**Owner:** Momentum 360  
**Product:** M360 Orbit, `https://momentum-360-agents.netlify.app/`  
**Scope:** The existing 19 Orbit specialists and the Momentum 360 operating system around them  
**Site status:** The existing production page is frozen. A second 19-agent page is specified for local or private staging, but this package does not modify or deploy the public site.  
**External-action status:** Connectors remain disabled for product workflows. The six communications in `communications/draft-registry.md` were separately and explicitly approved for scheduled delivery; nothing else in this package authorizes sending, publishing, spend, account changes, prospect contact, or client delivery.

## Purpose

Turn the existing 19-agent Orbit experience into a governed Momentum 360 knowledge and workflow system, then express Jesse's AI pipeline, Jason's operating decisions, and Momentum Intel through a second staged product page without changing the current live product while the operating model is validated.

## Completion standard

This package is complete only when:

1. Every one of the 19 existing Orbit specialists has a mission, boundaries, required inputs, source hierarchy, diagnostic framework, output templates, SOPs, quality gates, approval rules, KPIs, evaluation cases, failure modes, and cross-agent handoffs.
2. Current factual claims are tied to direct authoritative sources with an access date.
3. Momentum-specific knowledge and client-specific knowledge are separate namespaces.
4. The public preview, internal operating system, client workspaces, and external-action layer have distinct permissions.
5. No agent can silently send, publish, spend, change an account, or contact a lead.
6. The proposed pipeline can be piloted without changing the live Orbit site.

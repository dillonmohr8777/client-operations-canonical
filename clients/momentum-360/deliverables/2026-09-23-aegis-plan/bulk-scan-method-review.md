# Bulk scan method review

Reviewed the DOM collector, analyzer, and two seed page records locally on 2026-09-23. No pages were rescanned.

1. **Capture denominator:** `analyzeRecord` treats only `blocked === true` as unavailable. A failed or partial capture with missing `blocked`, `url`, `capturedAt`, or content arrays can earn a capture pass; empty arrays can earn passes for images, links, forms, and iframes. Validate capture completeness before content checks. Report requested, valid inspected, blocked, and invalid captures separately; do not include blocked or invalid captures in inspected-page pass totals.
2. **Malformed link false negative:** The collector stores resolved `a.href`, while the duplicated-scheme check expects the raw `https://https://` prefix. Browser URL parsing turns `https://https://bad.test` into `https://https//bad.test`, so the check can miss the defect. Capture `getAttribute('href')` for this check or detect the normalized form as well.
3. **Dynamic widget findings:** The seed homepage has 7 untitled iframes and 7 blank/about:blank iframe sources; local SEO has 3 untitled and 7 blank/about:blank. Chat, reCAPTCHA, and injected widgets are present. Attribute third-party/runtime iframe findings and treat uncertain ownership as advisory; a cross-origin iframe's internal content is outside this DOM scan.
4. **Accessible-name limits:** The collector does not capture `aria-labelledby`, SVG title, or visibility state for links. It accepts any nonempty `aria-labelledby` reference and any associated label for form fields without checking referenced or label text. It checks only inputs inside `<form>`. Thus both false failures and false passes are possible. Describe these as DOM heuristics and review affected elements before declaring accessibility compliance.
5. **Indexability limits:** `robots()` passes when robots metadata is absent. The capture cannot inspect HTTP `X-Robots-Tag`, robots.txt, or rendered search indexing, so its result means only that no DOM noindex was observed. Canonical comparison ignores scheme, query, and port; a valid same-path canonical may still point to a materially different URL. Name these limits in the report.
6. **Unneeded raw fields:** `scriptSrc` is unused by the analyzer and the seed capture contains a script URL with an `api_key` query parameter. Omit it from future raw captures and sanitize existing raw artifacts. The analyzer's privacy projection alone does not protect raw files.

The two seed records are public DOM snapshots, not evidence of site-wide accessibility, crawlability, HTTP status, or final lazy-loaded content.

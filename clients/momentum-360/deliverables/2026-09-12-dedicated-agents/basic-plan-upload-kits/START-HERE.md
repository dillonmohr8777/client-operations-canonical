# Momentum lightweight AI upload kits

Give each person only their named Markdown file. Each file is self-contained. They do not need the source reports, code, Slack archives, or the other four role files.

## Three steps
1. Open a fresh chat in a company-approved AI service. Upload your file if supported; otherwise paste its contents. You do not need a custom assistant or API.
2. Say: "Use this as my working brief. Wait for my task."
3. Fill in the file's task template with only the relevant facts or excerpt. Ask for one useful result.

## Keep usage light
Default replies target 250 words. Research, connected tools, media generation, agent delegation, and background work are off unless requested. Reuse the same chat for related tasks; supply changes instead of reposting everything. Ask for "handoff" to get a summary under 150 words when moving to a new chat.

These files reduce repeated context and unnecessary work. They cannot guarantee a provider's message allowance, upload support, or usage limits. They guide the model but do not enforce billing limits. If a limit is reached, save a handoff and resume later.

Only share data approved for that service. The kits contain role instructions and task templates, not private conversation histories, client records, or credentials. Results remain drafts for the person to review. These chat kits do not run the separate Slack/Zapier automation stack.

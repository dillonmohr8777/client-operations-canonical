# Need Momentum homepage concepts

Two independent long-form homepage builds for review:

- `map` — Orbital Growth Map, a faithful evolution of “Put Your Business on the Map.”
- `signal` — Kinetic Signal Field, a new particle-and-motion direction.

Need Momentum is the master agency brand in both concepts. Momentum 360 is the spatial-media service.

## Local commands

```text
npm install
npm run dev:map
npm run dev:signal
npm test
npm run typecheck
npm run build
```

Static builds are written to `dist/map` and `dist/signal`. See `DEPLOYMENT.md` for the two live Netlify review sites.

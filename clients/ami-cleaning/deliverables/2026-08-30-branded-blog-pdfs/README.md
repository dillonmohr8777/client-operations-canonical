# AMI August 2026 branded article PDFs

Ten review PDFs of the August facility articles, branded from the live AMI site. Not published on WordPress.

## Brand source

Captured 2026-08-30 from `https://www.ami-cleaning.com/`.

- Exact logo: `brand/ami-logo-transparent.webp` and a PNG print copy. Live file `ami-logo-transparent.webp`.
- Display type: Fraunces. Body type: Inter.
- Field: forest `#1A3A2A`, teal `#163040`, deep `#0B1620`.
- Lime `#4FA63B` is the I-bar and spray accent only. Body links use `#146C43`.
- Paper `#F7FAFB` and ink `#0F2230` for reading pages.

The logo tagline is white. It sits only on a dark AMI field. The mark is not redrawn, recolored, or placed on people.

## Rebuild

```
node scripts/build-ami-branded-blog-pdfs.mjs
```

Uses headless Chrome. Writes `html/`, `pdfs/`, and cover screenshots in `review/`.

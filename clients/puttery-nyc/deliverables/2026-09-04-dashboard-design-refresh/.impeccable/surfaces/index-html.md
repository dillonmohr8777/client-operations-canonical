# Puttery NYC dashboard

Mode: Operate.

The operator should identify what currently works, what still needs evidence, and the next action before reading the long integration worksheet.

The spatial thesis is a compact Puttery masthead and purpose row followed immediately by dated current status and an action panel. Technical counts and routing details live in the expanded evidence. Ten integration systems become scannable disclosure rows. The example reporting view is explicitly collapsed. The discovery worksheet remains a focused dark work surface with stable questions and export behavior.

At desktop widths the sidebar provides predictable section anchors and scrolls when the viewport is short. At mobile widths it becomes a horizontal strip. Mobile worksheet progress is a compact link so integration status appears before the old readiness card would have occupied the screen.

Keep the official logo, black/pink/teal palette, and compact Fugaz title. Use one 24-unit outline icon family, with golf-dimple geometry only as a quiet surface detail. Avoid ambient or scripted entrance motion.

Scope: layout, hierarchy, icon family, texture, current evidence wording, storage-error feedback, and URL persistence for view filters. Do not alter question IDs, wipe stored answers, change financial data into reported values, or introduce an external data connection.

Proof order: current status → next action → source readiness → detailed evidence → integration access → discovery questions → outcome definitions and pilot acceptance.
